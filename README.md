## İstifadə Olunan Əsas Git Komandaları
1. Git init- Yeni lokal repository yaradır.
2. git status - Faylların və dəyişikliklərin vəziyyətini göstərir.
3. git add - Dəyişiklikləri staging sahəsinə əlavə edir.
4. git commit -m - Dəyişiklikləri mesajla yadda saxlayır.
5. Git log online - Commit tarixçəsini qısa formada göstərir.
6. Git swith -c - Yeni branch yaradıb həmin branch-ə keçir.
7. Git mergw - Branch-i cari branch ilə birləşdirir.
8. Git push - Commit-ləri uzaq repository-yə (GitHub) göndərir.
